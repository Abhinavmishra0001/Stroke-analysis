# Project outputs

These files were generated by running `src/stroke_analysis.py` against the Healthcare Stroke dataset.

- `model_metrics.csv`: hold-out test-set metrics for both supervised models.
- `cluster_summary.csv`: descriptive statistics for the exploratory K-Means segments.
- `silhouette_scores.csv`: scores used to select the number of clusters.
- `figures/`: EDA, model-performance, and PCA segmentation charts.

Results can vary slightly if the source data changes or a different random seed is selected.
